Aufgabe 2: Screenshots speichern und finden

Windows 10

Dein Ziel: Du findest deinen Screenshot-Ordner. Du speicherst ein Bild von diesem Ordner und fügst es unten auf dieser OneNote-Seite ein.

Du arbeitest auf dieser OneNote-Seite in einem eigenen Edge-Tab. Lass auch den Teams-Tab offen. Deine Bilder und Antworten kommen unten zu Meine Arbeit.



1. Ein Bild als Datei speichern

Mit Windows + Umschalt + S wird auf Windows 10 ein Bild kopiert. Es ist normalerweise noch keine gespeicherte Datei.

  1. Lass diese OneNote-Seite auf dem Bildschirm sichtbar.
  2. Drücke Windows + Druck. Das macht ein Bild vom ganzen Bildschirm und speichert es als Datei.

Die Taste heißt manchmal Drucken, PrtSc oder PrtScn. Auf manchen Tastaturen musst du zusätzlich Fn halten.

2. Den Explorer öffnen

Der Explorer zeigt dir Dateien und Ordner. Ein Ordner ist wie eine Mappe für Dateien.

  1. Drücke Windows + E. Der Explorer öffnet sich. Du kannst auch unten auf den gelben Ordner klicken.
  2. Klicke links auf Bilder. Du siehst es nicht? Klicke zuerst auf Dieser PC.
  3. Suche Screenshots oder Bildschirmfotos. Öffne den Ordner mit zwei schnellen Klicks.
  4. Suche das gerade gemachte Bild. Öffne es mit zwei Klicks. Ist es das richtige? Schließe nur die Bildansicht wieder.

Klicke links auf Bilder. Öffne dann den Ordner Bildschirmfotos.

Hilfe: Ich finde den Ordner oder das Bild nicht

  • Schau links unter OneDrive. Öffne dort Bilder → Screenshots oder Bildschirmfotos.
  • Hast du beim Speichern selbst einen anderen Ordner gewählt? Schau dort nach.
  • Hast du nur Windows + Umschalt + S gedrückt? Dann ist dein Bild meist nur kopiert. Speichere es mit der Hilfe unten.

Ein Bild selbst speichern

  1. Mache mit Windows + Umschalt + S einen Screenshot.
  2. Klicke auf Start. Tippe Paint. Öffne Paint.
  3. Drücke Strg + V, dann Strg + S.
  4. Wähle links Bilder. Klicke auf Neuer Ordner. Nenne ihn Meine Screenshots und öffne ihn.
  5. Nenne das Bild Mein erster Screenshot.png. Wähle als Dateityp PNG. Klicke auf Speichern.
  6. Öffne im Explorer diesen Ordner. Das ist jetzt dein Screenshot-Ordner.

Klappt auch das nicht? Zeige auf.



3. Ein Bild vom Ordner machen

  1. Lass deinen Screenshot-Ordner im Explorer offen.
  2. Drücke Windows + Umschalt + S. Ziehe ein Rechteck um das Explorer-Fenster.
  3. Auf dem Bild müssen der Weg zum Ordner oben und die Dateien sichtbar sein.
  4. Klicke auf Start. Tippe Paint. Öffne Paint.
  5. Drücke dort Strg + V. Jetzt siehst du das Bild vom Ordner.

Paint unter Windows 10: das eingefügte Bild vom Screenshot-Ordner.



4. Das Bild speichern und kopieren

  1. Klicke in Paint auf Datei → Speichern unter → PNG-Bild.
  2. Öffne im Speicherfenster deinen Screenshot-Ordner aus Schritt 2.
  3. Nenne das Bild A2-Mein-Screenshot-Ordner.png. Klicke auf Speichern.
  4. Klicke in Paint auf Auswählen → Alles auswählen. Oder drücke Strg + A.
  5. Drücke Strg + C. Jetzt ist das ganze Bild kopiert.

Klicke auf Datei → Speichern unter → PNG-Bild.

Wähle deinen Ordner. Gib bei Dateiname den Namen A2-Mein-Screenshot-Ordner.png ein. Klicke auf Speichern.
