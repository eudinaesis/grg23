Windows 10

Aufgabe 3: Pfeile und Rahmen

Dein Ziel: Dein Screenshot zeigt einen Pfeil und einen Rahmen. Damit zeigst du, wo man klicken soll.

Prüfe zuerst dein Windows!

Diese Anleitung ist für Windows 10. Das Start-Zeichen ist meist weiß und unten links.

Du hast Windows 11? Öffne diese Aufgabe für Windows 11 →

Unsicher? So prüfst du es genau
  1. Drücke Windows + R.
  2. Tippe winver. Drücke Enter (⮐).
  3. Lies im neuen Fenster: Steht dort Windows 10 oder Windows 11?
  4. Schließe das kleine Fenster. Wähle die passende Anleitung.

Die Farbe und der Platz des Start-Zeichens können anders eingestellt sein. Der Name in diesem Fenster ist eindeutig.

Deine Bilder und Antworten kommen auf deine OneNote-Seite. Öffne sie wie unten gezeigt. Diese Webseite hilft dir bei den einzelnen Schritten.

Die OneNote-Seite öffnen

  1. Öffne die passende Aufgabe in Teams.
  2. Suche unter Meine Arbeit den OneNote-Link.
  3. Klicke rechts neben dem Link auf die drei Punkte ….
  4. Klicke auf Öffnen in….
  5. Klicke auf OneNote für das Web.

Die OneNote-Seite öffnet sich in einem eigenen Tab in Edge. Lass den Teams-Tab offen.

1. Einen Screenshot in Paint öffnen

  1. Öffne eine Seite mit einem Knopf oder Link, zum Beispiel die Aufgaben in Teams.
  2. Drücke Windows + Umschalt + S. Ziehe ein Rechteck um den Teil, den du zeigen willst.
  3. Klicke auf Start. Tippe Paint. Öffne Paint.
  4. Drücke Strg + V. Dein Screenshot erscheint.
Unter Windows 10 bearbeiten wir das Bild in Paint. Hier gibt es fertige Pfeile und Rechtecke.

2. Einen Pfeil zeichnen

  1. Klicke oben auf Start, falls du die Zeichenwerkzeuge nicht siehst.
  2. Suche Formen. Wähle den Pfeil nach rechts.
  3. Klicke auf Farbe 1. Wähle Rot.
  4. Beginne links neben dem Knopf oder Link, den du zeigen willst. Halte die linke Maustaste gedrückt.
  5. Ziehe nach rechts. Die Pfeilspitze soll auf den Knopf oder Link zeigen. Lass los.
  6. Klicke einmal neben den Pfeil. Jetzt ist er fertig.

3. Einen Rahmen zeichnen

  1. Wähle bei Formen das Rechteck.
  2. Klicke auf Füllung → Keine Füllung. So bleibt der Text sichtbar.
  3. Wähle bei Kontur eine durchgehende Linie. Wähle bei Größe eine dickere Linie.
  4. Ziehe ein Rechteck um den Knopf oder Link. Lass los.
  5. Klicke einmal neben den Rahmen. Jetzt ist er fertig.
Etwas ist schiefgegangen? Drücke Strg + Z. Das macht die letzte Änderung rückgängig. Versuche es noch einmal.

4. Das fertige Bild kopieren

  1. Drücke in Paint Strg + A. Damit wählst du das ganze Bild aus.
  2. Drücke Strg + C. Damit kopierst du das Bild mit Pfeil und Rahmen.

Meine Arbeit in OneNote

Klicke oben in Edge auf den Tab mit deiner OneNote-Seite.

Füge dein Bild unter dem Aufgabentext und über dem Beispielbild ein. Klicke dort auf eine freie Stelle. Drücke Strg + V.

Schreibe darunter: Mein Pfeil zeigt auf …

Prüfen und abgeben

  • Mein Screenshot hat einen Pfeil und einen Rahmen.
  • Die Pfeilspitze zeigt auf den richtigen Knopf oder Link.
  • Der Text im Rahmen ist lesbar.
  • Pfeil und Rahmen sind auch im eingefügten Bild sichtbar.

Klicke oben in Edge auf den Teams-Tab. Öffne dort wieder die passende Aufgabe, falls nötig. Klicke oben rechts auf Abgeben. Prüfe: Steht dort Abgegeben?
