Windows 10

Aufgabe 4: Ein digitales Bild ganz nah

Dein Ziel: Du vergrößerst einen Screenshot. Du findest heraus, wie ein digitales Bild aufgebaut ist.

Prüfe zuerst dein Windows!

Diese Anleitung ist für Windows 10. Das Start-Zeichen ist meist weiß und unten links.

Du hast Windows 11? Öffne diese Aufgabe für Windows 11 →

Unsicher? So prüfst du es genau
  1. Drücke Windows + R.
  2. Tippe winver. Drücke Enter (⮐).
  3. Lies im neuen Fenster: Steht dort Windows 10 oder Windows 11?
  4. Schließe das kleine Fenster. Wähle die passende Anleitung.

Die Farbe und der Platz des Start-Zeichens können anders eingestellt sein. Der Name in diesem Fenster ist eindeutig.

Deine Bilder und Antworten kommen auf deine OneNote-Seite. Öffne sie wie unten gezeigt. Diese Webseite hilft dir bei den einzelnen Schritten.

Die OneNote-Seite öffnen

  1. Öffne die passende Aufgabe in Teams.
  2. Suche unter Meine Arbeit den OneNote-Link.
  3. Klicke rechts neben dem Link auf die drei Punkte ….
  4. Klicke auf Öffnen in….
  5. Klicke auf OneNote für das Web.

Die OneNote-Seite öffnet sich in einem eigenen Tab in Edge. Lass den Teams-Tab offen.

1. Einen kleinen Screenshot machen

  1. Suche auf einer Webseite ein Wort und ein kleines Symbol.
  2. Drücke Windows + Umschalt + S. Mache einen kleinen Screenshot von dem Wort und dem Symbol.
  3. Klicke auf Start. Tippe Paint. Öffne Paint.
  4. Drücke Strg + V. Dein Bild erscheint.

2. Ganz nah hinschauen

  1. Suche in Paint unten rechts den Regler mit − und +.
  2. Klicke mehrmals auf +. Vergrößere das Bild so weit wie möglich.
  3. Suche mit den Rollbalken dein Wort oder Symbol, wenn es aus dem sichtbaren Bereich gerutscht ist.
  4. Schau auf die Ränder. Siehst du kleine Kästchen oder Treppenstufen?
Vergrößere das Bild in Paint. Nimm den Zoom-Regler. In Windows-10-Paint ist Strg + + kein Zoom-Befehl.

3. Die vergrößerte Ansicht zeigen

  1. Lass die vergrößerte Ansicht in Paint offen.
  2. Drücke noch einmal Windows + Umschalt + S.
  3. Ziehe ein Rechteck um ein Stück mit gut sichtbaren Kästchen oder Treppenstufen.
  4. Lass los. Dieses neue Bild ist jetzt kopiert.
Mache wirklich einen neuen Screenshot von der vergrößerten Ansicht. Wenn du in Paint nur das Bild kopierst, wird die Vergrößerung nicht mitkopiert.

Meine Arbeit in OneNote

Klicke oben in Edge auf den Tab mit deiner OneNote-Seite.

Füge dein Bild unter dem Aufgabentext und über dem Beispielbild ein. Klicke dort auf eine freie Stelle. Drücke Strg + V.

Denk nach

Schreibe deine Antworten unter dein Bild:

  1. Was siehst du an den Rändern der Buchstaben oder des Symbols?
  2. Siehst du beim Vergrößern neue Einzelheiten? Oder werden nur die Kästchen größer?
  3. Was hat das mit einem digitalen Bild zu tun? Nutze die Wörter Bildpunkte und Zahlen.
Hilfe zu Frage 3

Ein digitales Bild besteht aus vielen kleinen Bildpunkten. Sie heißen auch Pixel. Der Computer speichert die Farbe jedes Bildpunkts als Zahlen. Beim Vergrößern werden die vorhandenen Bildpunkte größer. Neue Einzelheiten kommen nicht dazu.

Manche Programme zeigen die Ränder weich an. Dann wirkt das Bild unscharf. Es besteht trotzdem aus einzelnen Bildpunkten.

Prüfen und abgeben

  • Mein Bild zeigt die stark vergrößerte Ansicht.
  • Ich habe alle drei Fragen beantwortet.

Klicke oben in Edge auf den Teams-Tab. Öffne dort wieder die passende Aufgabe, falls nötig. Klicke oben rechts auf Abgeben. Prüfe: Steht dort Abgegeben?
