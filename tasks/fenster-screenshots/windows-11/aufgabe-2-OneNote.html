Aufgabe 2: Screenshots speichern und finden

Windows 11

Dein Ziel: Du findest deinen Screenshot-Ordner. Du speicherst ein Bild von diesem Ordner und fügst es unten auf dieser OneNote-Seite ein.

Du arbeitest auf dieser OneNote-Seite in einem eigenen Edge-Tab. Lass auch den Teams-Tab offen. Deine Bilder und Antworten kommen unten zu Meine Arbeit.

1. Einen Screenshot machen

  1. Lass diese OneNote-Seite auf dem Bildschirm sichtbar.
  2. Drücke Windows + Umschalt + S. Ziehe ein Rechteck um einen Teil der Seite.
  3. Lass los. Der Screenshot ist jetzt kopiert.

Das neue Snipping Tool speichert Screenshots meist auch als Datei. Das automatische Speichern kann aber ausgeschaltet sein.

2. Den Screenshot-Ordner finden

Der Explorer zeigt dir Dateien und Ordner. Ein Ordner ist wie eine Mappe für Dateien.

  1. Drücke Windows + E. Oder klicke unten auf den gelben Ordner.
  2. Klicke links auf Bilder. Du siehst es nicht? Schau unter Dieser PC oder Start im Explorer nach.
  3. Öffne Screenshots oder Bildschirmfotos mit zwei schnellen Klicks.
  4. Suche dein neues Bild. Öffne es mit zwei Klicks. Ist es das richtige? Schließe nur die Bildansicht wieder.

Hilfe: Ich finde mein Bild nicht

  1. Schau unter OneDrive → Bilder → Screenshots oder Bildschirmfotos nach.
  2. Öffne über Start das Snipping Tool. Klicke auf … → Einstellungen.
  3. Suche die Einstellung zum automatischen Speichern von Screenshots. Wenn dort ein Ordner steht, öffne ihn im Explorer.
  4. Ist das automatische Speichern aus? Oder gibt es die Einstellung nicht? Speichere dein Bild selbst: siehe unten.

Windows-11-Snipping-Tool: Einstellungen zum automatischen Speichern und Speicherordner.

Das Bild selbst speichern

  1. Mache mit Windows + Umschalt + S einen neuen Screenshot.
  2. Klicke unten rechts auf die Screenshot-Meldung oder ihr kleines Bild. Wenn du Markup und Freigabe siehst, klicke darauf.
  3. Klicke auf Speichern unter oder das Disketten-Zeichen.
  4. Wähle Bilder. Erstelle dort mit Neuer Ordner einen Ordner Meine Screenshots. Öffne ihn.
  5. Nenne das Bild Mein erster Screenshot.png. Wähle den Dateityp PNG. Klicke auf Speichern.
  6. Öffne diesen Ordner im Explorer. Das ist jetzt dein Screenshot-Ordner.

Klappt es nicht? Zeige auf.

3. Ein Bild vom Ordner machen

  1. Lass deinen Screenshot-Ordner im Explorer offen.
  2. Drücke Windows + Umschalt + S. Ziehe ein Rechteck um das Explorer-Fenster.
  3. Auf dem Bild müssen der Weg zum Ordner oben und die Dateien sichtbar sein.
  4. Klicke unten rechts auf die Screenshot-Meldung oder ihr kleines Bild. Wenn du Markup und Freigabe siehst, klicke darauf.

Die Meldung ist weg? Drücke Windows + N. Schau in den Benachrichtigungen nach deinem Screenshot. Ist er auch dort nicht? Mache den Screenshot noch einmal.

4. Das Bild speichern und kopieren

  1. Klicke im Snipping Tool auf Speichern unter oder das Disketten-Zeichen.
  2. Wähle deinen Screenshot-Ordner. Nenne das Bild A2-Mein-Screenshot-Ordner.png. Klicke auf Speichern.
  3. Drücke im Snipping Tool Strg + C. Jetzt ist dein Bild kopiert.
