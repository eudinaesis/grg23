Windows 11

Aufgabe 1: Zwei Fenster und ein Screenshot

Dein Ziel: Diese Aufgabe ist links. Die allgemeinen Anleitungen sind rechts. Ein Screenshot zeigt beide Fenster.

Prüfe zuerst dein Windows!

Diese Anleitung ist für Windows 11. Das Start-Zeichen ist meist blau und unten in der Mitte.

Du hast Windows 10? Öffne diese Aufgabe für Windows 10 →

Unsicher? So prüfst du es genau
  1. Drücke Windows + R.
  2. Tippe winver. Drücke Enter (⮐).
  3. Lies im neuen Fenster: Steht dort Windows 10 oder Windows 11?
  4. Schließe das kleine Fenster. Wähle die passende Anleitung.

Die Farbe und der Platz des Start-Zeichens können anders eingestellt sein. Der Name in diesem Fenster ist eindeutig.

Deine Bilder und Antworten kommen auf deine OneNote-Seite. Öffne sie wie unten gezeigt. Diese Webseite hilft dir bei den einzelnen Schritten.

Die OneNote-Seite öffnen

  1. Öffne die passende Aufgabe in Teams.
  2. Suche unter Meine Arbeit den OneNote-Link.
  3. Klicke rechts neben dem Link auf die drei Punkte ….
  4. Klicke auf Öffnen in….
  5. Klicke auf OneNote für das Web.

Die OneNote-Seite öffnet sich in einem eigenen Tab in Edge. Lass den Teams-Tab offen.

1. Die Anleitungen öffnen

Ein Tab ist ein Reiter ganz oben in Edge. Ein Fenster kann mehrere Tabs haben.

  1. Lass diese Aufgabe in Edge offen.
  2. Öffne unsere allgemeinen Anleitungen. Sie öffnen sich in einem neuen Tab.
Links in OneNote öffnen: Klicke auf den blauen, unterstrichenen Link. Ein kleines Kästchen erscheint. Klicke darin noch einmal auf den Link neben dem Globus 🌐. Die Seite öffnet sich in einem neuen Tab.

2. Aus dem Tab ein Fenster machen

  1. Zeige mit der Maus auf den Tab der allgemeinen Anleitungen ganz oben.
  2. Halte die linke Maustaste gedrückt. Ziehe den Tab deutlich nach unten, weg von der Tab-Leiste.
  3. Lass los. Jetzt haben die allgemeinen Anleitungen ein eigenes Fenster.

3. Die Fenster nebeneinander legen

  1. Klicke in das Fenster mit dieser Aufgabe. Halte die Windows-Taste gedrückt. Drücke die linke Pfeiltaste ⬅.
  2. Die Aufgabe ist jetzt links. Wenn Windows kleine Fenster zur Auswahl zeigt, klicke auf die allgemeinen Anleitungen.
  3. Sind die Anleitungen noch nicht rechts? Klicke in ihr Fenster. Drücke Windows + ➡.
  4. Prüfe: Aufgabe links. Allgemeine Anleitungen rechts.
Nimm die Pfeiltasten unten rechts auf der Tastatur. Nimm nicht die große Löschtaste über Enter. Auch auf ihr ist ein Pfeil nach links.
Ohne Tastatur

Halte oben am Fenster eine freie Stelle neben den Tabs mit der linken Maustaste fest. Ziehe das Fenster bis zum linken Bildschirmrand. Wenn eine Vorschau erscheint, lass los. Ziehe das andere Fenster genauso an den rechten Rand.

4. Einen Screenshot machen

Ein Screenshot ist ein Bild vom Bildschirm.

  1. Drücke Windows + Umschalt + S. Der Bildschirm wird dunkler.
  2. Wähle oben das Rechteck, wenn es noch nicht gewählt ist.
  3. Halte die linke Maustaste gedrückt. Ziehe ein Rechteck um beide Fenster. Die beiden Seitentitel sollen sichtbar sein.
  4. Lass los. Das Bild ist jetzt kopiert.
Füge das Bild gleich ein. Wenn du etwas anderes kopierst, ersetzt es das Bild.

Meine Arbeit in OneNote

Klicke oben in Edge auf den Tab mit deiner OneNote-Seite.

Füge dein Bild unter dem Aufgabentext und über dem Beispielbild ein. Klicke dort auf eine freie Stelle. Drücke Strg + V.

Schreibe darunter: Welche zwei Tasten bringen ein Fenster nach links?

Prüfen und abgeben

  • Mein Bild zeigt beide Fenster und ihre Seitentitel.
  • Ich habe die beiden Tasten aufgeschrieben.

Klicke oben in Edge auf den Teams-Tab. Öffne dort wieder die passende Aufgabe, falls nötig. Klicke oben rechts auf Abgeben. Prüfe: Steht dort Abgegeben?
