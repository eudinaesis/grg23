Aufgabe 3: Pfeile und Rahmen

Windows 11

Dein Ziel: Dein Screenshot zeigt einen Pfeil und einen Rahmen. Damit zeigst du, wo man klicken soll.

Du arbeitest auf dieser OneNote-Seite in einem eigenen Edge-Tab. Lass auch den Teams-Tab offen. Deine Bilder und Antworten kommen unten zu Meine Arbeit.



1. Einen Screenshot öffnen

  1. Öffne eine Seite mit einem Knopf oder Link, zum Beispiel die Aufgaben in Teams.
  2. Drücke Windows + Umschalt + S. Ziehe ein Rechteck um den Teil, den du zeigen willst.
  3. Klicke unten rechts auf die Screenshot-Meldung oder ihr kleines Bild. Wenn du Markup und Freigabe siehst, klicke darauf.
  4. Das Bild öffnet sich im Snipping Tool.

Die Meldung ist weg? Drücke Windows + N. Suche sie in den Benachrichtigungen. Oder öffne das Snipping Tool über Start und mit Strg + O ein gespeichertes Bild aus Aufgabe 2.

2. Einen Pfeil zeichnen

  1. Klicke oben auf Formen. Der Knopf zeigt kleine Formen.
  2. Wähle den Pfeil und eine gut sichtbare Farbe, zum Beispiel Rot.
  3. Halte die linke Maustaste gedrückt. Ziehe den Pfeil bis zu dem Knopf oder Link, den du zeigen willst.
  4. Lass los. Die Pfeilspitze soll auf den Knopf oder Link zeigen.
  5. Klicke neben den Pfeil. Jetzt ist er fertig.

3. Einen Rahmen zeichnen

  1. Klicke wieder auf Formen. Wähle das Rechteck.
  2. Wähle bei Füllung Keine bzw. die durchgestrichene Farbe. So bleibt der Text sichtbar.
  3. Ziehe ein Rechteck um den Knopf oder Link.
  4. Klicke neben den Rahmen. Jetzt ist er fertig.

Etwas ist schiefgegangen? Drücke Strg + Z. Das macht die letzte Änderung rückgängig.

Hilfe: Pfeil und Rahmen in Paint

Öffne über Start das Programm Paint. Drücke Strg + V. Dein Screenshot erscheint. Mache dann diese Schritte:

Einen Pfeil aus drei Linien zeichnen

Die fertigen Pfeile in Paint zeigen nach oben, unten, links oder rechts. Mit drei Linien kannst du einen Pfeil zeichnen, der auch schräg zeigt.

  1. Suche oben Formen. Öffne bei Bedarf den kleinen Pfeil daneben.
  2. Wähle die Linie: den einfachen geraden Strich.
  3. Wähle oben bei den Farben Rot. Wähle bei Strichstärke eine dickere Linie.
  4. Zeichne eine lange Linie bis zu dem Knopf oder Link. Halte dafür die linke Maustaste gedrückt, ziehe und lass los.
  5. Klicke neben die Linie. Wähle wieder die Linie.
  6. Zeichne an ihrem Ende zwei kurze Linien als Pfeilspitze. Klicke nach jeder Linie daneben. Die Spitze zeigt auf den Knopf oder Link.

Einen Rahmen zeichnen

  1. Wähle bei Formen das Rechteck.
  2. Klicke auf Füllung → Keine Füllung. So bleibt der Text sichtbar.
  3. Wähle bei Kontur eine durchgehende Linie. Wähle bei Strichstärke eine dickere Linie.
  4. Ziehe ein Rechteck um den Knopf oder Link. Lass los.
  5. Klicke einmal neben den Rahmen. Jetzt ist er fertig.

Etwas ist schiefgegangen? Drücke Strg + Z. Das macht die letzte Änderung rückgängig. Versuche es noch einmal.

Wähle Keine Füllung. Dann bleibt der Text im Rahmen sichtbar.

So kann dein Bild aussehen: ein Rahmen und ein Pfeil aus drei Linien.

Das fertige Bild kopieren

  1. Drücke in Paint Strg + A. Damit wählst du das ganze Bild aus.
  2. Drücke Strg + C. Damit kopierst du das Bild mit Pfeil und Rahmen.
